tie-locus gallery · n=2 and n=3

Every possible {point, line, plane}k tie locus

Each figure is a genuine simultaneous tie among k features (real code: AffineQuadratic + bisector, not a mockup), placed so the marked point sits exactly on the locus. A tie among k features generically has codimension k−1, so k runs from 1 (no tie yet) to n+1 (isolated point(s) — the generic vertex of the diagram). Every shape name and point/degree count below is read directly off the bisector's own matrix (rank, signature, reducibility), not asserted. «plane» only exists as a feature type at n=3, and isn't yet an insertable input to the incremental construction — every case here is built directly from the same low-level quadric machinery the construction itself uses, one level below it. n=3 scenes are interactive — drag to rotate.

Locus curves/surfaces of dimension > 0 are point clouds from randomized Gauss–Newton projection onto the shared bisector system, not a mesh — density, not exactness, conveys the shape. Isolated-point cases (the last row of each section) show every real root a many-start Newton search actually finds for that construction, marked with a star, not just one canonical example — e.g. three mutual line-tangent points at n=2 shows all 4 real solutions (the incenter and 3 excenters of the triangle the lines form). Where the search finds fewer real roots than the Bezout upper bound on the caption, that's stated explicitly rather than assumed away: the bound isn't always reachable by real (as opposed to complex) solutions, and where it's unclear whether that's a fundamental limit or just a search gap, that uncertainty is the honest answer. The exact predicate kernel elsewhere in this project is a separate, exact code path; this gallery uses ordinary floats.
