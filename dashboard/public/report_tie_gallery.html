tie-locus gallery · n=2 and n=3

Every possible {point, line, plane}k tie locus

Each figure is a genuine simultaneous tie among k features (real code: AffineQuadratic + bisector, not a mockup), placed so the marked point sits exactly on the locus. A tie among k features generically has codimension k−1, so k runs from 1 (no tie yet) to n+1 (an isolated point — the generic vertex of the diagram). «plane» only exists as a feature type at n=3, and isn't yet an insertable input to the incremental construction — every case here is built directly from the same low-level quadric machinery the construction itself uses, one level below it.

Locus curves/surfaces of dimension > 0 are point clouds from randomized Gauss–Newton projection onto the shared bisector system, not a mesh — density, not exactness, conveys the shape. The exact predicate kernel elsewhere in this project is a separate, exact code path.
